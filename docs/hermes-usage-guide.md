# Hermes 使用指南

_小白整理的 Hermes Agent 使用文档。_

## 概述

Hermes 是 OpenClaw 的**工具执行专用 Subagent**，负责处理需要复杂工具链的任务。

```
┌─────────────────────────────────────────────┐
│              飞书 / WebChat                  │
│                   ↓                         │
│            OpenClaw Gateway                 │
│                   ↓                         │
│           Main Agent (小白)                  │
│                   ↓ (自动调用)               │
│           Hermes Agent                       │
│  ┌─────────┬─────────┬─────────┬─────────┐ │
│  │ 搜索    │ 浏览器  │ 代码执行 │ 文件操作 │ │
│  └─────────┴─────────┴─────────┴─────────┘ │
└─────────────────────────────────────────────┘
```

## 核心能力

| 能力 | 工具 | 用途 |
|------|------|------|
| **网络搜索** | web_search | 查资料、找信息 |
| **浏览器自动化** | browser | 网页操作、截图、表单填写 |
| **代码执行** | exec | 运行命令、脚本 |
| **文件操作** | read/write/edit | 读写文件 |
| **论文搜索** | arxiv | 学术研究 |
| **PDF 分析** | pdf | 文档解析 |
| **图片分析** | image | 图像识别 |

## 使用方式

### 方式一：飞书直接对话（推荐）

在飞书私聊或群组中直接发送需求，Main Agent 会自动判断是否需要调用 Hermes。

**示例对话**：

```
大哥：帮我搜索一下 OpenClaw 的最新更新

小白：正在为您搜索...（自动调用 Hermes web_search）

小白：根据搜索结果，OpenClaw 最新版本是 2026.5.7，主要更新包括...
```

### 方式二：显式指定调用

如果需要明确让 Hermes 处理，可以在对话中说明。

**示例**：
```
大哥：@小白 用 Hermes 帮我执行这个命令：docker ps

小白：调用 Hermes 执行命令...
结果：
CONTAINER ID   IMAGE                           STATUS
obsidian-vault filebrowser/filebrowser:v2      Up 2 hours
```

### 方式三：代码执行任务

```
大哥：帮我写个 Python 脚本统计日志文件中的错误数量

小白：调用 Hermes 编写并执行脚本...
（Hermes 编写代码 → 执行 → 返回结果）
```

## 工具详解

### 1. Web 搜索 (web_search)

**用途**：查找网络信息

**示例**：
```
搜索：Node.js 22 新特性
搜索：2024 年 AI 发展趋势
搜索：Docker 最佳实践
```

**返回**：
- 搜索结果摘要
- 来源链接
- 关键信息提取

### 2. 浏览器自动化 (browser)

**用途**：网页操作、截图、数据提取

**示例**：
```
打开 https://example.com 并截图
填写表单并提交
获取网页上的表格数据
```

**能力**：
- 页面导航
- 元素点击/输入
- 截图保存
- 内容提取

### 3. 代码执行 (exec)

**用途**：运行系统命令和脚本

**示例**：
```
执行：ls -la ~/src
执行：docker ps
执行：npm install
```

**安全限制**：
- 执行前确认（可配置）
- 禁止危险命令（rm -rf / 等）
- 超时控制（默认 30s）

### 4. 文件操作

**用途**：读写文件内容

**示例**：
```
读取 README.md
修改配置文件
创建新文件
```

## 配置信息

**Agent 定义**：
```json
{
  "id": "hermes",
  "name": "Hermes-Agent",
  "model": "moonshot/kimi-k2.5",
  "workspace": "/home/azureuser/.openclaw/workspace"
}
```

**工具权限**：
```json
{
  "tools": {
    "profile": "full",
    "exec": {
      "host": "gateway",
      "security": "full",
      "ask": "off"
    },
    "web": {
      "search": {
        "enabled": true,
        "provider": "kimi"
      }
    }
  }
}
```

## 故障排除

### 问题 1：工具执行超时

**现象**：命令执行很久没有返回

**解决**：
- 简化命令
- 分批执行
- 使用后台任务

### 问题 2：权限不足

**现象**：Permission denied

**解决**：
- 检查文件权限
- 使用 sudo（如果需要）
- 修改目录权限

### 问题 3：网络访问失败

**现象**：搜索/网页访问失败

**解决**：
- 检查网络连接
- 确认 DNS 配置
- 检查防火墙规则

## 最佳实践

### 1. 任务分解

复杂任务拆分成多个简单步骤：
```
❌ 一次性：帮我搭建一个完整的网站
✅ 分步骤：
   1. 创建项目目录
   2. 初始化 package.json
   3. 安装依赖
   4. 创建基础代码
```

### 2. 结果验证

重要操作后验证结果：
```
执行命令后：确认文件是否创建
搜索信息后：验证来源可靠性
```

### 3. 错误处理

失败时提供详细信息：
```
❌ 不行
✅ 错误：权限不足，需要 sudo 权限执行 docker 命令
```
